# Spécifications

Une spécification par lot, écrite et validée **avant** le code : `lotNN-<sujet>.md`.

Contenu attendu : objet, périmètre (dans / hors lot), objets natifs ERPNext utilisés, paramétrage livré en fixtures,
code ajouté (et pourquoi le natif ne suffit pas), contrôles, tests automatiques, scénario de test manuel, reprise / annulation.
